# Agent avatars

Approved v14 profile pictures from `output/art-direction/v14-agent-pfps/pfp-*.png`, reduced from 1024×1024 to 128×128 with nearest-neighbour sampling. The app shows them in `Avatar` (`src/client/ui.tsx`) for Codex, Claude and Gemini connections; other connections keep their initials. Render with `image-rendering: pixelated`.
